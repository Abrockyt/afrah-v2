# 20 / Architecture asset provenance
Original massing diagrams: authored for this study from the supplied conceptual envelope. No old Afrah geometry, façade, site plan or camera data is reused.
Building materials, HDRIs, landscaping and props remain planned. The asset manifest separates candidate, acquired, processed and approved status.
For each acquired file store source URL, creator, asset-specific licence/version, download date, original hash and derivative paths in `assets/licenses/`. For CC0 sources retain source evidence even where attribution is not mandatory.
Reference screenshots/recordings retain the original site's authorship and belong to the research library. A temporary study image needs an explicit future replacement ID before being put in a prototype.
No third-party 3D model or shader has been extracted from a reference page.
