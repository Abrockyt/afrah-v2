# 19 / Mobile strategy
Preserve the building story, not every desktop effect. Portrait uses one central hero camera, fewer trees, simpler shadows and smaller environment maps. Cap DPR and choose a mobile GLB using device capability plus measured frame cost.
If reduced-data mode, poor sustained frame cost or WebGL loss occurs, show original day/dusk posters and native chapter text. Preserve selected mode and scroll position when switching.
Avoid horizontal dragging as a required action. Day/Dusk is reachable with a thumb, with 44px targets and labels. Native scrolling stays available through every chapter.
Before acceptance test on physical mid-range Android and iPhone Safari, both portrait and landscape. Include thermal degradation after several minutes; a short desktop-emulated run is insufficient.
