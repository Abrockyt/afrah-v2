# 07 / Proposed material palette
| Material | Visual intent | PBR starting direction |
|---|---|---|
| Warm limestone-like stone | Main envelope, matte texture, restrained variation | Nonmetal; roughness 0.65–0.85 |
| Charcoal / dark bronze metal | Frames, railings, sheltered accents | Metalness 1; roughness 0.35–0.55 |
| Neutral glazing | Visible depth, limited mirror effect | Test physical material versus opaque environment response |
| Sheltered timber | Entry soffit only | Nonmetal; roughness 0.45–0.7 |
| Concrete | Foundation and hidden structure | Nonmetal; roughness 0.8 |
| Interior light | Varied warm windows | 2200–3200K intent; restrained emissive |
| Paving / landscape | Quiet scale cues | Shared neutral materials; no glossy ground |

Values are artistic starting points, not product specifications. Match albedo/normal/roughness scale and colour management. Default web maps 1K–2K; only genuine closeups justify 4K.
Original procedural swatches are sufficient for blockout; final texture procurement follows the asset list.
