# 02 / Reference component matrix
| Component | Source | Decision | Afrah adaptation / rejection |
|---|---|---|---|
| Building occupies most of viewport | Silver Pinewood | KEEP PRINCIPLE | One continuous original building in LAND → FORM → LIGHT. |
| Oversized introduction | Silver Pinewood | ADAPT | One 1–5-word heading, not a long uppercase paragraph. |
| Offset image edge | LIKOVA | ADAPT | Architecture may cross an editorial boundary; do not reproduce its wordmark silhouette. |
| Branded loading ornament | ERA | REJECT artwork; KEEP anticipation | Reveal the chosen Afrah footprint with a real loading state. |
| Persistent registration | Whiteley | KEEP PRINCIPLE | Later viewing CTA; prototype uses chapter navigation without a fake sales form. |
| Development/location navigation | Bankside | KEEP PRINCIPLE | Direct routes remain reachable without watching the story. |
| Promotional hero overlay | Bankside | REJECT | Protect first-view architecture and give contact its own navigation position. |
| Bespoke brand font files | All | REJECT reuse | Existing Afrah faces or system fallback; no extracted font binaries. |
| Muted HTML footage | LIKOVA | ADAPT | Lazy-load short optional bridges after the four-scene prototype. |
| Photograph/canvas contains words | Multiple | REJECT for Afrah UI | Native HTML headings, labels and controls per latest instruction. |

Every component must record its source role. Borrowing the scale of a heading does not authorize borrowing its wording, font files or building.
