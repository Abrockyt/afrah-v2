Use a fluid margin between anchors rather than seven independent layouts. Full-bleed media can exceed the content cap. Keep captions aligned to the content grid.

Spacing scale: 4, 8, 12, 16, 24, 32, 48, 64, 80, 96, 128, 160, 192, 256.
Utility row: 24px gap. Heading/support gap: 24px desktop, 16px mobile. Editorial section separation: 160px desktop, 80px mobile. Scene composition uses viewport-relative negative space without locking text into fixed heights.
Body measure: 40–58 characters. Editorial split: start at 7 image columns / 5 text columns; use 61.8/38.2 only where the composition improves.
