# 10 / First four scenes
View original schematic keyframes in [the visual review](../review.html#storyboard). They communicate framing, not final render quality.

| Keyframe | Composition | Camera / architecture | Native text |
|---|---|---|---|
| 00 / prepare | Black, fine footprint line near centre, ample margin | No heavy scene required | AFRAH; measured status or “Preparing the view” |
| 01 / land | Building site occupies lower-right; open sky/space above | Wide elevated view; site perimeter and planted edge | “A place takes shape.” |
| 02 / structure | Core and floor plates resolve; keep base fixed | Slow settling three-quarter approach | “A frame for living.” |
| 03 / form | Recessed glazing, slabs and terraces make one silhouette | Finish camera before next event | Optional small chapter number only |
| 04 / light | Full building stays stationary | Sun/environment changes continuously | Day / Dusk; optional conceptual time marker |
| 05 / hold | Blue-grey environment with varied warm windows | Same silhouette, no reload | “Stay a little longer.”; Replay |

Reserve no-copy intervals between title appearances. On portrait screens compose the building centrally, controls below the title, no tiny desktop HUD.
Sound remains off until requested. If no licensed sound is ready, omit the sound control instead of shipping a nonfunctional toggle.
