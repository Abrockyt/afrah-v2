# 15 / Sources and licences
Checked 2026-09-23. These are source-level findings; no catalogue asset has been downloaded for production.

- [Poly Haven](https://polyhaven.com/license): asset files are CC0. Use normal supported download/API routes; website content and example renders have different terms.
- [ambientCG](https://docs.ambientcg.com/license/): downloadable assets and material previews are CC0.
- [Pexels](https://www.pexels.com/license/): photos/video can be used and modified under its licence, with listed restrictions. Record asset/creator and avoid implying that stock architecture is Afrah.
- [Mixkit](https://mixkit.co/license/): licences differ by item/type. Verify the specific selection.
- Freesound, BlenderKit, Sketchfab and Fab remain candidate sources; no licence inference from “free” or “downloadable”.

Reference-site screenshots and recordings: private study evidence, source credited, production clearance unknown. Latest user instruction allows temporary public images; the manifest must distinguish temporary reference use from an approved production asset. Do not extract font files, models or shader code.

Required manifest fields: id, name, type, source URL, creator, licence URL, licence, acquisition date, path, scene, status, replacement ID, notes. Unknown values remain null rather than invented.
