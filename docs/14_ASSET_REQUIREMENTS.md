# 14 / Asset requirements
| Asset | Required for first prototype? | Specification / substitute |
|---|---|---|
| Original building | Yes | Exterior blockout, addressable construction groups |
| Site and planted edge | Yes | Simple original geometry, consistent scale |
| Day environment | Yes | Neutral overcast, small web environment |
| Dusk environment | Yes | Same horizon direction, blue hour |
| Stone / glazing / metal | Yes | Shared PBR materials; 1K–2K maps where visible |
| Hero poster | Yes | Render from the original concept, day and dusk |
| Wordmark image | No | Native AFRAH text per latest instruction |
| Heading graphics | No | Native HTML text |
| Final apartment plans | No | Await floor-program review |
| Interior film | No | Later ENTER / LIFE stage |
| Sound | Optional | Omit until sourced and functioning |

Image placeholders keep a fixed ratio and a useful caption. Reference screenshots remain in the research library; any future temporary image used in a prototype records its source and replacement asset ID. All media can be swapped through a manifest.
