# 03 / Afrah story
**A place becomes a home through form and light.** The original building is the recurring subject. No fictional residents, invented neighbourhood or inherited tower claims.

| Chapter | Visual event | User purpose | Exit condition |
|---|---|---|---|
| LOAD | Footprint line on warm black | Understand preparation | Actual critical asset settles or fallback appears |
| LAND | Wide site, orientation, planted edge | Locate the footprint | Camera establishes scale |
| FORM | Core, slabs, façade and glazing resolve | Recognize the architecture | Complete stationary silhouette |
| LIGHT | Same camera, changing daylight | Discover Day / Dusk | User can hold either state |
| MATERIAL | Stone recess and handrail detail | Read proposed material intent | One editorial pause |
| ENTER | Approach sheltered arrival | Establish a human scale | Glazing fills view |
| LIFE | Original/licensed detail footage | Imagine everyday occupation | Short, optional sequence |
| EXPLORE | Stable selectable floor model | Find residence information | Accessible residence list |
| PLACE | Pull back to real map, once known | Understand context | Verified locations only |
| HOME | Return to the first camera in dusk | Recognize arrival | Private viewing or enquiry |

Prototype ends after LIGHT, with replay and a return to the beginning. Later chapters are planned, not dummy navigation destinations.
