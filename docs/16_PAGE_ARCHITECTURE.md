# 16 / Page architecture
| Route | Main job | Content dependency |
|---|---|---|
| / | Cinematic building story | Original scene and copy |
| /residences | Find a home | Approved unit schedule and plans |
| /architecture | Explain design | Reviewed concept and credited drawings |
| /interiors | Materials and spaces | Original interior work |
| /lifestyle | Everyday detail | Credited footage and verified services |
| /amenities | Practical shared spaces | Approved amenity schedule |
| /location | Local context | A real site and verified map data |
| /journal | Editorial updates | Dated approved articles |
| /about | Team / approach | Verified brand and team content |
| /private-viewing | Enquiry | Real destination, privacy text and delivery backend |

The first prototype has only the four story chapters and replay. Do not create dead inner-page links or a fake submitted enquiry.
Home provides a direct practical route once residence data exists. Inner pages use an editorial layout and do not repeat the cinematic loader. Residence filters preserve URL state; a native table/list accompanies any floor canvas.
