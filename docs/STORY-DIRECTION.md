# AFRAH — A different nature

Latest user instruction supersedes ERA-first navy/peach. Expand the project into a genuinely multipage architectural story. Primary visual authority: Composites.archi, supported by ERA, Likova and Silver Pinewood. Refero searches reviewed monochrome architectural, residential and experimental editorial directions; Norgram supports sharp image-led grids, mostlikely supports technical notation, Samara supports detailed residence discovery but its palette and rounded surfaces are rejected.

## Reference decisions
| Decision | Evidence | Application |
| --- | --- | --- |
| Graphite / silver / chalk; heavy tight sans type | Composites live capture, Tasa Orbiter font | Global identity, menus, contrast between chapters |
| A spatial narrative with a visible chapter index | Composites introduction / cases / materials | Home and vision: nature → form → light → everyday → home |
| Actual sculptural geometry, independently rendered in silver | Composites public shape and tunnel GLBs | Scroll-reactive homepage sculpture and design page |
| Tower/sky layering and a drawn city | ERA | Architecture chapter, architectural model viewer |
| Day/night building layers and stepped masks | Likova live assets and recordings | Architecture detail interaction, angular image transition |
| Nature, water, movement and inset editorial imagery | Silver Pinewood live page and recordings | Landscape page, daily rhythm chapter, journal |
| Flat, bordered image indices | Norgram / Composites cases | Main navigation, chapter directory and residence results |

These are qualitative visual choices, not claims that one section has a proven conversion rate. The goal is to alternate immersive moments with useful information and clear exits, preserve native scrolling and reduced motion, and give each page a complete narrative.

## Pages
Home / The vision / Architecture / Landscape / Interiors / Residences / Journal (+ three articles) / Contact. Each subject has its own URL and page content, next chapter navigation, and enquiry access. Residential information is conceptual, with illustrative plans, not invented real-world availability or location facts.

## Tokens and motion
Ink #111111, graphite #242424, silver #b4b0ae, chalk #eeedeb, muted #797775. Tasa Orbiter bold display and regular text; tiny uppercase technical captions; hard edges; thin rules. Photography retains restrained natural color. No navy, copper accents or ornamental serif. Scroll motion follows reading order; no repeated full-page loading between routes. Responsive compositions, native links, keyboard controls, reduced motion and per-section lazy 3D.
