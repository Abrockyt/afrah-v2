DAY / DUSK SYSTEM
============================================================

Do NOT call this normal "dark mode".

The control is:

DAY / DUSK

DAY:

- architectural ivory surfaces
- daylight building
- natural landscape
- dark text
- neutral windows
- daylight HDRI/environment

DUSK:

- blue-hour environment
- deep charcoal / dusk surfaces
- warm interior window lights
- warm reflections
- darker landscaping
- off-white text
- subtle environmental ambience

Do not turn it into full midnight.

Think approximately:

20–40 minutes after sunset.

- building must not disappear/reload
- interpolate materials where possible
- crossfade environment
- animate light intensity
- animate window emissive material
- update UI colours
- update environmental audio gently

Target transition:
roughly 1.2–2.5 seconds depending on implementation.

Use physically believable lighting.

============================================================
MOBILE
============================================================

Mobile is NOT a reduced desktop screenshot.

Redesign cinematic moments.

Possible:

live WebGL construction.

mobile:
optimized model + pre-rendered transition.

desktop:
3D interactive map.

mobile:

Maintain:

quality
clarity

while reducing GPU/network cost.

============================================================

============================================================

Do not lock accessibility behind cinematic animation.

============================================================
PERFORMANCE
============================================================

Performance is part of luxury.

Target excellent Core Web Vitals.

Do not preload the entire cinematic experience.

LANDING SHELL:
lightweight.

Then load:

next chapter
then next chapter.

Use:

route splitting
code splitting
dynamic imports
lazy loading
intersection observers
smart prefetch
texture compression
mesh compression
responsive media

Avoid:
- enormous JS bundles
- 8K browser textures
- 100MB initial model
- giant uncompressed video
- dozens of custom fonts

============================================================
WEBGL PERFORMANCE
============================================================

Monitor:

FPS
GPU memory
draw calls
triangles
texture memory
DPR
shader complexity

Target:
smooth 60fps where hardware permits.

Gracefully degrade.

DPR may be clamped for expensive scenes.

Do not render invisible scenes continuously.
