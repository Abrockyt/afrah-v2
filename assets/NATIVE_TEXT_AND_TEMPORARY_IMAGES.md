# Native text and temporary image policy
Latest user instruction, 23 September 2026: use public reference imagery for the study when helpful; use native text when image recreation is difficult; replace temporary material later.

Implement titles as h1/h2, utility labels as real button/link text, and AFRAH as a typographic wordmark until a approved mark exists. Do not rasterize text or hide the only accessible label inside a canvas.
Keep copy separate from media. Future image slots use stable IDs, aspect ratio, alt text, source, status and replacement ID. Original architecture remains the aim of the study.
This package uses native text, original SVG massing diagrams and source screenshots. It does not require scraped full-resolution photography to communicate the direction.
