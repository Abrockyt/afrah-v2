# Acquisition records
No external production HDRI, texture, model, font, footage or sound file has been acquired in this package.
Reference capture provenance is recorded in ../../asset-manifest.json.
For each future acquisition create a JSON record with source URL, creator, licence/version, licence URL, download date, hash, original file path, derivatives, usage restrictions and review status.
Source-level licence findings are in ../../docs/15_ASSET_SOURCES_AND_LICENSES.md. Check asset-level exceptions before updating status.
